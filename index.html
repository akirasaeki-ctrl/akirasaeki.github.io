Phase 1: Local Intranet Architecture

Router vs. Switch Topology Analysis

In this phase of the network architecture design, the structural differences between Layer 2 and Layer 3 devices were analyzed. A Switch operates primarily at the Data Link layer, utilizing MAC addresses to forward data packets efficiently within a single Local Area Network (LAN). It creates dedicated collision domains for each connected device, maximizing internal bandwidth.

Conversely, a Router operates at the Network layer, routing data packets between distinct network segments using IP addresses. While switches facilitate intra-network communication, routers act as gateways to connect the local intranet to external networks (such as the Internet), managing broadcast domains and enforcing traffic policies.

Thermal and Dimensional Constraints Analysis

As semiconductor manufacturing approaches atomic scales, physical constraints present major hurdles to Moore's Law. Shrinking transistors increases current leakage and power density, generating immense heat that traditional silicon structures cannot easily dissipate. Furthermore, sub-nanometer dimensions trigger quantum tunneling, where electrons breach insulating barriers and cause data corruption. To sustain performance scaling, modern hardware engineering must shift from pure physical shrinking toward alternative chip architectures, such as 3D integrated circuits (stacked dies) and specialized materials like gallium nitride.

3. Efficiency & Pseudocode Analysis

Pseudocode Implementation

BINARY_SEARCH(Array, target)
    low = 0
    high = length(Array) - 1
    
    WHILE low <= high
        mid = (low + high) / 2
        IF Array[mid] == target THEN
            RETURN mid
        ELSE IF Array[mid] < target THEN
            low = mid + 1
        ELSE
            high = mid - 1
        ENDIF
    ENDWHILE
    RETURN -1
ENDFUNCTION

Big O Notation Complexity Comparison

In IBDP Computer Science, evaluating algorithm efficiency is vital. While a Linear Search has a time complexity of $O(n)$ because it examines every element sequentially, a Binary Search operates at $O(\log n)$ efficiency. This logarithmic scaling makes Binary Search exponentially faster for processing large-scale enterprise datasets.
